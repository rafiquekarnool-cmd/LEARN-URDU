# URDU SIKHE — GitHub Build

This project is prepared for GitHub Actions.

## Build
1. Upload/extract the contents of this folder into the root of a GitHub repository.
2. Push to `main` or `master`, or open **Actions → Android Build → Run workflow**.
3. After the workflow finishes, download the APK/AAB from **Artifacts**.
